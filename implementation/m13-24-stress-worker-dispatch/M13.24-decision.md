# M13.24 Decision

## STRESS_PARALLEL_DISPATCH_READY

`--stress-cells` with `--workers > 1` now uses the existing validated parallel seed/profile group runner. Sequential `--workers 1` is unchanged. Stress-cell count semantics are unchanged.

### Root cause

`execute_benchmark`’s `stress_cells` branch called `run_stress_benchmark` without `workers`, so `run_cell_benchmark` defaulted to 1. Sequential metadata then overwrote CLI `workers=8`.

### Proof

- Progress: `parallel workers=2` / `parallel workers=8`
- Metadata: `workers=2` / `workers=8`
- Fingerprints: workers 1, 2, 8 identical
- Resume: workers=8 stop_after_cell=5 then resume matches uninterrupted
- Memory: estimated parallel peak 0.83 GB at workers=8, `memory_safe=true`
- Official benchmark **not** executed

### Unchanged

Benchmark config, PolicyPack, epsilon, seeds, profiles, metrics, M8, B3.
